Language model training

      
The lip model produces raw text; a small language model cleans it up
        (grammar, word choice). Train it on your own sentences with
        POST /train-lm — paste one sentence per line.

      
      
      

        
      

      

    


    

      
API settings

      
The frontend calls the backend at this base URL. Default is same-origin
        /api (the FastAPI server serves these files and proxies its own API under /api).
        Change it only if the backend runs somewhere else.

      

        
        
      

      
You can also set it with a query string: ?api=http://localhost:8000,
        or before load: window.SUBVOX_API_BASE.
